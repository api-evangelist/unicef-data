UNICEF Data is the official open data platform of the United Nations Children's Fund, providing programmatic access to global child welfare statistics, health and nutrition indicators, education data, child protection metrics, MICS (Multiple Indicator Cluster Survey) results, and SDG indicators for children across countries worldwide. The primary API is an SDMX REST web service exposing UNICEF's Data Warehouse, which contains 748+ indicators organized into thematic dataflows covering demography, maternal and child health, nutrition, HIV/AIDS, WASH, education, and gender. All data is freely accessible without authentication, licensed under Creative Commons Attribution 3.0 IGO.

**Areas:** Children · Child Welfare · Global Health · Statistics · SDG · MICS · Education · Nutrition · SDMX · Open Data · United Nations · UNICEF

## How this profile is made
